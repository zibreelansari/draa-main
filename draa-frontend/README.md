# DRAA Corporate Website

Public website for DRAA (OPC) Private Limited, an education services and knowledge management company.

## Included

- Corporate home, about, capabilities and audience pages
- Detailed pages for five DRAA service lines
- Study in India guidance tools
- Learning and events page
- Frontend-only contact enquiry flow
- Responsive layouts and accessible reduced-motion support

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The project is intentionally frontend-only. It does not contain authentication, payments, dashboards, student/admin systems, or a backend API.
